# 041 목표비중 설정 · 계좌 유형 필터 · 보유상품 합산 · 유형별 국가 비중

## 요구사항
1. 목표비중을 화면에서 직접 설정한다. 기타에는 현금 및 현금성 자산을 포함한다.
2. 계좌 필터를 기본계좌 · ISA · IRP · 연금저축 · CMA로 나눈다.
3. 보유상품은 계좌와 상관없이 같은 상품을 합산하고, 평가액·수익금·수익률의 높은순/낮은순으로 정렬한다.
4. 국가별 도넛 아래에 ETF · 개별주식 · 현금성(통화·채권·예금)의 국가별 비중을 보여준다.

## 결정
- 목표비중 저장: 모든 기기에 공유(Supabase `family_vault.data.targets`). 전용 API `POST /api/family-targets`가 targets만 바꾼다. 세션·같은 출처·revision 일치를 확인하고, 조건부 update로 동시 수정 시 409를 반환한다.
- 목표 기준: 전체 자산. [한국 주식, 중국 주식, 미국 주식, 기타(현금·CMA·예금·채권·그 밖의 나라 주식)]. 저장하면 `targetsBasis: "nav"`가 기록되고, 없으면 이전 주식 기준 값이라는 안내를 보여준다.
- 계좌 유형: 위탁종합·종합위탁 → 기본계좌, CMA·CMA(RP형) → CMA, 개인종합자산관리계좌 → ISA, 연금저축 → 연금저축, 퇴직연금운용·IRP → IRP.
- 상품 유형: `Product.kind`가 우선이고, 없으면 ETF 브랜드명(KODEX·TIGER·RISE 등)과 예금 여부로 추정한다. 혼합 ETF의 채권 부분은 현금성 행으로 보내며 `bondCountry`로 국가를 나눈다(없으면 예금은 한국, 채권은 기타). 외화 현금은 `Account.cashByCurrency`(원화 환산액, 합계 = cash)로 해당 국가에 배분한다.
- 스키마 변경 없음. 새 필드는 모두 선택 항목이다.
