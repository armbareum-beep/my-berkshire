# 우리집 자산

가족·증권사·계좌별 투자자산, 현금흐름 기반 XIRR, 주식의 국가별 비중을 관리하는 가족용 앱입니다.

기존 ENUF 로그인·대시보드·메뉴·API와 예약 작업을 종료하고 이 앱으로 교체했습니다. 이전 데이터베이스를 삭제하거나 공개하지 않습니다.

## 사용

1. 엑셀·거래내역은 ChatGPT 대화에 첨부합니다.
2. 계좌주·계좌·거래내역·목표비중을 확인한 뒤 승인된 비공개 저장소에 반영합니다.
3. 사이트는 가족 비밀번호로 로그인해 조회합니다. 유일한 예외로 국가 목표비중 4칸만 화면에서 수정할 수 있습니다(`POST /api/family-targets`). 업로드와 계좌·보유상품·현금·입출금의 입력·수정·삭제 기능은 없습니다.

자료는 비공개 Supabase 테이블에서 읽습니다. 휴대폰·컴퓨터에서 같은 자료를 보며, 화면에 돌아오거나 30초마다 새 버전을 확인합니다. 시세 조회는 화면의 평가금액만 갱신하고 저장된 금융자료는 변경하지 않습니다. 공용 기기에서는 보관함을 잠그세요.

이전 localStorage 자료는 자동 업로드하지 않으며 새 앱에서 읽지 않습니다. ChatGPT 파일 첨부 자체가 자동 동기화는 아닙니다. 작업 시 접근 가능한 관리자 경로로 검증된 데이터를 반영해야 하며, 웹사이트 로그인 쿠키로 자료를 수정할 수 없습니다.

개인 금융자료는 공개 저장소와 정적 배포 파일에 절대로 추가하지 않습니다. 실데이터 백업은 사용자에게 비공개 파일로 제공합니다.

## 계산과 자료 범위

- 기준일의 보유수량 × 원화가격 + 현금으로 평가합니다. 가격 누락은 0원으로 간주하지 않고 표시합니다.
- XIRR은 실제 날짜별 입금(-), 출금(+), 기말 평가액(+)으로 계산합니다. 계좌 수익률을 평균하지 않습니다. 입력 이력이 완전하다고 확인한 계좌만 수익률을 표시합니다.
- 시작 전부터 자산이 있었다면 시작일 평가액을 음수 현금흐름으로 입력해야 합니다.
- 내부이체는 두 계좌 모두를 조회할 때 제외하고 한쪽만 조회할 때 포함합니다. 같은 날짜·같은 금액으로 연결된 두 건을 검증합니다.
- 국가 비중 도넛은 주식 노출만 분모로 하며 현금·채권을 제외합니다. 혼합상품은 입력한 비중으로 나눕니다.
- 도넛 아래에서 ETF·개별주식·현금성(현금·채권·예금)의 국가 비중을 따로 보여줍니다. 상품의 `kind`(stock/etf/deposit/bond)가 없으면 이름으로 추정합니다. 채권 부분의 국가는 `bondCountry`가 없으면 상품명(예: 미국채 → 미국)으로 판단합니다. 현금은 계좌의 `cashByCurrency`(통화별 원화 환산액)로 원화·달러·엔화 등 통화별로 표시합니다.
- 목표비중은 전체 자산 기준 한국·중국·미국 주식과 기타(현금·CMA·예금·채권·그 밖의 나라 주식) 4칸입니다. 저장 시 세션·같은 출처·revision을 확인해 다른 기기의 변경을 덮어쓰지 않습니다.
- 계좌 필터는 계좌 유형을 기본계좌(위탁)·ISA·IRP(퇴직연금)·연금저축·CMA로 묶습니다. 보유상품은 같은 종목을 계좌와 상관없이 합산하며 평가액·수익금·수익률로 정렬합니다.
- 시세 갱신은 종목코드만 서버에 전달합니다. Yahoo 가격과 환율을 원화로 환산하며, 일부 누락 시 기존 평가 전체를 유지합니다. 지연 가격일 수 있습니다.
- 시세 갱신은 수량·현금·입출금 내역을 갱신하지 않습니다. 기준일 이후 매매가 있으면 먼저 잔고와 이력을 반영해야 합니다.

## 개발

```sh
npm ci
npm run dev
npm test
npm run typecheck
npm run build
```

필수 서버 환경변수: `FAMILY_PASSWORD_HASH`(무작위 salt + `:` + scrypt 64바이트 hex), `FAMILY_SESSION_SECRET`(32자 이상의 무작위 비밀), `NEXT_PUBLIC_SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`. 비밀번호·해시·세션 비밀·금융자료를 코드나 공개 환경변수에 넣지 않습니다. 새 가족 테이블 마이그레이션과 비공개 초기 자료 등록이 배포 전에 필요합니다. 기존 사용자/계좌 테이블은 수정하지 않습니다.

비밀번호는 서버에서 비교하고 7일 HttpOnly·Secure·SameSite=Strict 쿠키를 발급합니다. 비밀번호 해시나 세션 비밀을 바꾸면 기존 세션이 무효화됩니다. 로그인은 IP당 15분에 5회, 전체 30회로 데이터베이스에서 원자적으로 제한하며 저장소 장애 시 차단합니다. 자료 읽기·시세·목표비중 API가 세션을 검사합니다. 자료 API는 GET만 제공하며, 로그인·로그아웃·시세·목표비중 요청은 같은 출처에서만 허용합니다. 목표비중 API는 `targets` 외의 자료를 바꾸지 않습니다. 테이블 RLS는 활성화되어 있고 anon/authenticated 권한은 없습니다.
