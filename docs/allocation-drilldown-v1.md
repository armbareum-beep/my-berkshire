# 자산배분 드릴다운 v1 — 아래로 파고들 뿐 옆으로 고르지 않는다

> 작성: 2026-08-14
> 선행 문서: `target-lens-spec-v1.md`(렌즈·비례 스케일은 유효) · `design-strategy-v1.md` §4
> 결정 사항: 렌즈 **탭**을 **계층**으로 전환 · 기준 토글 폐지 · 렌즈는 잎에서만

---

## 0. 왜 또 바꾸나

`target-lens-spec-v1.md` 는 옳은 원칙(진실은 하나, 렌즈는 여럿)을 세웠지만 **그걸 한 화면에
전부 얹었다.** 렌즈 탭 4개 + 기준 토글 + 묶음 조정 + 통화 줄 + 편집 입력칸.

사용자 피드백: **"좀 짜증나는게 단계별로 쉽게 갔으면 좋겠어. 처음에는 전체 자산이 있잖아
→ 금융자산 → 주식 선택해서 주식에 관한거 다 볼 수 있게. 지금 너무 복잡하지 않냐?"**

맞다. 이 저장소가 이미 두 번 진단한 실패 모드다.

> 기능을 하나씩 옳게 만들었지만 **한 화면에 계속 쌓았다.** — `allocate-redesign-v1.md` §0

자본배분은 레일로 풀었다(`allocate-rail-v2.md`). 자산배분만 아직 탭이었다.

---

## 1. 목표 상태 — 한 화면은 한 계층

```text
/allocation                     전체 자산 ₩100,000,000
   ├ 금융자산  70%  ›
   ├ 현금      20%  ›
   └ 실물자산  10%  ›            (→ /networth)
        │
/allocation/financial           금융자산 · 전체 자산의 70%
   ├ 주식   60%  목표 45%  ›
   ├ ETF    30%  목표 25%  ›
   └ 코인   10%           ›
        │
/allocation/financial/주식      주식 · 금융자산의 60%
   [ 42% → 목표 45%   [45] % [목표 맞추기] ]
   [종목별] [국가별] [산업별]      ← 렌즈는 여기서만
   도넛 + 목록

/allocation/cash                현금 · 통화별 목표
/allocation/targets             종목 목표비중 정하기(검색형)
```

**아래로 파고들 뿐 옆으로 고르지 않는다.** 렌즈는 더 내려갈 곳이 없는 **잎에서만** 나온다 —
위 계층까지 렌즈를 깔면 "지금 어느 각도로 보는 중인지"를 매 화면 신경 써야 한다.

---

## 2. 기준 토글이 사라졌다

v1 의 "전체 대비 / 이 묶음 안에서" 토글은 **드릴다운에서 필요 없어진다.**

지금 보는 계층이 곧 분모이기 때문이다 — 금융자산 화면의 100% 는 금융자산이고, 주식 화면의
100% 는 주식이다. 대신 상단에 **부모 맥락 한 줄**을 늘 붙인다("전체 자산의 70%").

사용자가 지적한 *"주식 안에서 누르면 비율만 바뀌니까 어디서 바꿔야 할지 모르잖아"* 가
구조적으로 해소된다. 고르는 행위 자체가 없어졌다.

---

## 3. 남은 비대칭 — 목표의 분모

| | 분모 |
|---|---|
| 계층 비중 | 그 계층(이 화면의 100%) |
| **목표비중** | **금융자산 + 현금** — 저장·엔진이 쓰는 기준(`lib/targetLens.ts`) |

실물자산은 목표비중 대상이 아니다. 그래서 **0계층(전체 자산)에는 목표를 아예 표시하지
않는다** — 분모가 달라 합이 안 맞는 숫자가 나오느니 안 보여준다.

행마다 기준을 적으면 글자가 늘어 다시 복잡해지므로 **화면당 한 번** 각주로 밝힌다.

## 5. 왜 `/allocation/targets` 만 계층 밖인가

"아직 한 주도 없는 기업에 목표를 매기는" 일은 **계층 어디에도 속하지 않는다** — 아직
자산이 아니라 어느 칸에도 안 들어간다. 그래서 한 가지 일만 하는 화면으로 뺐다.
진입은 금융자산 계층 하단 링크와 `/allocate/settings` 카드 둘뿐이다.

통화 목표(`CASH:*`)는 여기 섞지 않는다 — 통화는 종목이 아니고 `/allocation/cash` 가 맡는다.

### 홈 딥링크 — 3계층으로 받는다

홈 자산구성 카드의 국가 탭은 `/allocation/country?only=한국` 이었다. 리다이렉트로만 받으면
**`only` 필터가 사라져** 전체 국가 목록으로 떨어진다. 그래서 묶음을 한 단계 더 파고드는
`pick` 을 만들었다.

```text
주식 → 국가별 → 한국        /allocation/financial/주식?by=country&pick=한국
```

`pick` 상태에서는 **그 묶음이 화면의 주어**가 된다 — 제목·평가액·목표 조정 대상이 전부
"한국"으로 바뀌고, 비중 분모도 한국 안이 된다. 홈 링크는 리다이렉트를 거치지 않고 이 자리를
직접 가리킨다.

**남은 한계:** 예전 `?only=한국` 은 한국 **주식+ETF** 를 함께 보여줬다. 새 계층에서는 국가가
유형 아래에 있어 "한국 주식"과 "한국 ETF"가 갈린다. 홈 링크는 주식 쪽으로 보낸다 — 계층을
지키는 대가다.

### 문을 안 달아서 아무도 못 들어갔다 (2026-08-14 추가)

사용자 피드백: ***"뭘 바꿨다는거야? 똑같은데?"*** — 맞는 말이었다.

화면 다섯 장을 만들어놓고 **진입 동선을 안 만들었다.**

| 경로 | 실제 목적지 |
|---|---|
| 하단 **자본배분 탭** | `/allocate` — 배분 레일. 드릴다운이 아니다 |
| 홈 자산구성 카드 헤더 | `/allocation/financial` — **전체 자산 계층을 건너뛴다** |
| `/allocate/settings` | `/allocation/targets` — 편집기만 |
| **`/allocation`(전체 자산)** | **어디서도 링크하지 않음** |

하단 탭으로 다니면 예전과 똑같이 보이는 게 당연했다. 만든 사람만 URL을 알고 있었던 셈이다.

**고친 것**

- 홈 자산구성 카드 헤더 `자산구성 ›` → `/allocation`(전체 자산). 드릴다운은 꼭대기부터 탄다
- 자본배분 레일 1단계에 `내 자산배분 보기` → `/allocation`. **하단 탭에서 닿는 유일한 문**이다
- `/rebalance` 안내 화면도 같은 입구로

> 교훈: 화면을 만들었으면 **거기로 가는 길**을 같은 커밋에서 만든다. 라우트가 빌드에
> 잡히는 것과 사용자가 닿는 것은 다른 문제다.

### 메뉴가 셋이었다 — 계층을 목표의 분모에 맞춘다 (2026-08-14 추가)

사용자 지적: ***"지금 계층이 자본배분, 지금비중, 비중설정 이렇게 3가지잖아? 너무 복잡한데...
검색해서 하니까 부자연스럽고 계층으로 못 나누니까 여기서 비중설정하는 게 의미없어 보여."***

**뿌리 원인 — 계층과 목표의 분모가 어긋나 있었다.**

목표비중은 **금융자산+현금을 100%** 로 보고 매긴 값이다(§16.2 — 목표를 안 채운 나머지가 곧
현금). 그런데 화면에서는 금융자산과 현금이 전체 자산 아래 **서로 다른 가지**였다. 그래서
*어느 화면에서도 목표 합이 100% 로 보이지 않았다.* 비중 설정이 겉도는 게 당연했다.

```text
before                          after
전체 자산                        전체 자산
├ 금융자산  ← 목표 일부           ├ 투자자산  ← 목표 합 = 100%
│  └ 주식 / ETF / 코인            │  └ 주식 / ETF / 코인 / 현금
├ 현금      ← 목표 나머지         └ 실물자산 (조회만)
└ 실물자산
```

**투자자산 계층에서 주식·ETF·코인·현금이 한 줄에 나란히 선다.** 이 화면의 목표 합이 곧
100% 이고, 그게 그대로 배분 엔진이 쓰는 값이다.

실물자산은 목표 대상이 아니다(사용자 확인) — 부동산은 쌀 때 사는 것이지 "비중 맞춰 사는"
게 아니라 배분 대상과 성격이 다르다. 조회만 하고 목표는 안 매긴다. **저장된 목표 숫자가
재해석되지 않는다**는 뜻이기도 하다.

### 메뉴를 셋에서 둘로

`/allocation/targets`(검색형 편집 화면)를 **없애고 `+ 종목 추가` 버튼으로 접었다.**
지금 보고 있는 계층에 종목을 더하는 동작이 된다 — 목표만 정하러 다른 화면으로 나가지
않는다. `/allocate/settings` 의 목표비중 카드도 뺐다.

| | before | after |
|---|---|---|
| 자본배분(돈 넣기) | `/allocate` | `/allocate` |
| 지금 비중(조회) | `/allocation/*` | `/allocation/*` — **보면서 그 자리에서 정한다** |
| 비중 설정(편집) | `/allocation/targets` · `/allocate/settings` 카드 | **없앰** |

검색 자체는 남는다 — 아직 한 주도 없는 기업은 목록에 없으니 찾는 수밖에 없다
(`TargetSearchModal` 주석). 다만 **별도 화면이 아니라 계층 안의 버튼**이다.
